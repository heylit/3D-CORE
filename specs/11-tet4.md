# SPEC 11 — 3B dört düğümlü tetrahedron eleman (tet4) (Dalga 2)

## Amaç
3B katı modelleri (`Model.dim = 3`) dört düğümlü doğrusal tetrahedron (tet4, sabit şekil değiştirmeli
eleman) ile çözmek: `ke`, düğüm DOF'ları, eleman gerilme tensörü. SPEC 01'in birleştirme ve çözücü
iskeleti değişmeden kullanılır; SPEC 12 (gmsh) ve SPEC 13 (von Mises + CalculiX) bunun üstüne kurulur.

## Teori

### Şekil fonksiyonları ve hacim
Düğümler `x_a = (x_a, y_a, z_a)`, `a = 1..4` (`element.nodes` sırasında). Doğrusal şekil fonksiyonları:
```
N_a(x, y, z) = α_a + β_a x + γ_a y + δ_a z          Σ N_a = 1
        ┌ 1  x1  y1  z1 ┐
    C = │ 1  x2  y2  z2 │        det C = 6V (işaretli)
        │ 1  x3  y3  z3 │
        └ 1  x4  y4  z4 ┘
[α; β; γ; δ] = C⁻¹      (C⁻¹'in a. sütunu = N_a'nın katsayıları)
V = |det C| / 6
```
`∂N_a/∂x = β_a`, `∂N_a/∂y = γ_a`, `∂N_a/∂z = δ_a` eleman içinde sabittir; bu yüzden şekil değiştirme
ve gerilme eleman içinde sabittir (CST'nin 3B karşılığı).

**Düğüm sırası:** `det C` işareti düğüm sırasına bağlıdır (sağ el / sol el). `ke` ve gerilme işaretten
bağımsızdır (`C⁻¹` iki sırada da doğru gradyanı verir, hacim `|det C|/6`), bu yüzden **iki sıra da kabul edilir**
ve aynı sonucu verir. Bozuk (yassı) eleman: `V ≤ 1e-12 · ℓ_max³` (`ℓ_max` = en uzun kenar) → `ModelError`.

### Şekil değiştirme – yer değiştirme (B) matrisi
Eleman DOF vektörü `d = [u1, v1, w1, u2, v2, w2, u3, v3, w3, u4, v4, w4]` (12). Voigt düzeni
**CalculiX / Abaqus düzeni** (SPEC 13 çapraz kontrolü kolay olsun diye), kayma bileşenleri mühendislik
kayması `γ = 2ε`:
```
ε = [ε_xx, ε_yy, ε_zz, γ_xy, γ_xz, γ_yz]ᵀ = B d

        ┌ β_a   0    0  ┐
        │  0   γ_a   0  │
B_a  =  │  0    0   δ_a │          B = [B_1  B_2  B_3  B_4]   (6 x 12)
        │ γ_a  β_a   0  │
        │ δ_a   0   β_a │
        └  0   δ_a  γ_a ┘
```

### Malzeme (D) matrisi — izotrop doğrusal elastik
```
λ = E ν / ((1 + ν)(1 − 2ν))        G = E / (2(1 + ν))
        ┌ λ+2G   λ     λ    0  0  0 ┐
        │  λ    λ+2G   λ    0  0  0 │
D  =    │  λ     λ    λ+2G  0  0  0 │          σ = D ε
        │  0     0     0    G  0  0 │          σ = [σ_xx, σ_yy, σ_zz, τ_xy, τ_xz, τ_yz]ᵀ
        │  0     0     0    0  G  0 │
        └  0     0     0    0  0  G ┘
```
`D` sadece `−1 < ν < 0.5` için pozitif tanımlıdır; aksi → `ModelError` (`ν = 0.5`'te `λ` sonsuz).

### Rijitlik matrisi ve gerilme
```
ke = ∫_V Bᵀ D B dV = V · Bᵀ D B         (12 x 12, simetrik, pozitif yarı tanımlı)
σ  = D B d                              (eleman başına sabit, 6 bileşen)
```
`ke`'nin çekirdeği tam olarak 6 rijit cisim modudur (3 öteleme + 3 küçük dönme): 6 sıfır özdeğer, 6 pozitif.

### Global sistem
Değişmez: SPEC 01'deki `K u = F`, `R = K u − F`. 3B modelde düğüm başına 3 DOF (`ux, uy, uz`),
`model.dof_index` ile numaralanır. Yükler düğüm kuvvetleridir (yayılı yükün düğümlere dağıtımı
çağıranın işidir; düzgün yüzey çekmesinde doğrusal üçgen yüz için her köşeye `t·A/3`).

### Patch test ve kilitlenme
- tet4 doğrusal yer değiştirme alanını tam üretir: sınıra doğrusal alan yazılınca iç düğümler aynı
  alanı ve her eleman aynı sabit gerilmeyi verir (Irons patch testi). Yakınsamanın gerek şartıdır.
- Uyumlu (compatible) yer değiştirme elemanı olduğu için ağ inceldikçe **genelleştirilmiş esneklik**
  `W = Fᵀ u` aşağıdan ve iç içe (nested) ağlarda **monoton artarak** gerçek değere yaklaşır.
- tet4 eğilmede çok rijittir (kayma kilitlenmesi): kaba ağda konsol uç sehimi gerçeğin %20'si kadar
  çıkabilir. Bu bir hata değil, elemanın bilinen davranışıdır; kabul kriterleri buna göre konmuştur.

Kaynaklar: Logan, *A First Course in the Finite Element Method*, Bölüm 11 (3B gerilme analizi, tetrahedron);
Zienkiewicz–Taylor–Zhu, *The Finite Element Method: Its Basis and Fundamentals*, Bölüm 6 ve 9 (patch test);
Timoshenko–Goodier, *Theory of Elasticity* (konsol, Saint-Venant).

## Arayüz

### `core/elements/tet4.py`
- `volume(element, model) -> float` — `V = |det C| / 6` [mm³]. Bozuk eleman → `ModelError`.
- `B(element, model) -> np.ndarray (6, 12)`
- `D(material) -> np.ndarray (6, 6)` — `ν ∉ (−1, 0.5)` → `ModelError`
- `ke(element, model) -> np.ndarray (12, 12)`
- `dofs(element, model) -> list[int]` — `[ux1, uy1, uz1, ux2, ..., uz4]`, `element.nodes` sırasında,
  `model.dof_index` ile
- `strain(element, model, u) -> np.ndarray (6,)` — `ε = B d`
- `stress(element, model, u) -> np.ndarray (6,)` — `σ = D B d` [MPa]
- Hata durumları (hepsi `ModelError`): `model.dim != 3`; `len(element.nodes) != 4`; aynı düğüm iki kez;
  bozuk eleman; geçersiz `ν`. `element.section` kullanılmaz (verilirse yok sayılır).
- `axial_force` **yoktur**: katı elemanın eksenel kuvveti tanımsızdır.

### Eleman sözleşmesi (`core/elements/__init__.py`)
`ke` ve `dofs` her elemanda zorunlu. `axial_force` sadece çubuk tipi elemanlarda, `stress` sadece katı
elemanlarda bulunur. Kayıt: `ELEMENTS["tet4"] = tet4`.

### `core/post.py`
- `element_forces(model, u)` ve `element_stresses(model, u)`: sadece `axial_force` sağlayan elemanları
  içerir (davranış `bar1d` için aynı). tet4 elemanları bu sözlüklerde **yer almaz**; böylece `solve()`
  ve `Result` değişmeden tet4 modelini çözer.
- Yeni: `element_stress_tensors(model, u) -> dict[int, np.ndarray]` — `stress` sağlayan her eleman için
  eleman id → `σ` (6,) [MPa], Voigt düzeni yukarıdaki gibi.

Kullanım: `r = solve(model)`, `sigma = post.element_stress_tensors(model, r.u)`.
(`Result`'a gerilme tensörü alanı eklemek `core/model.py` değişikliğidir; gerekirse SPEC 13 öncesi ayrı
arayüz PR'ı.)

## Kabul kriterleri
- [ ] **K1** Tek eleman, birim köşe tetrahedronu `(0,0,0), (1,0,0), (0,1,0), (0,0,1)`: `V = 1/6`, `B` ve `ke`
  el hesabıyla tam değer (rel 1e-12); `ke` simetrik; özdeğerler: tam 6 sıfır (`|λ| ≤ 1e-10·λ_max`), 6 pozitif —
  `tests/unit/test_tet4_element.py`
- [ ] **K2** Rijit cisim hareketi (öteleme + küçük dönme `u = c + ω × x`) sıfır şekil değiştirme ve sıfır gerilme
  verir; `ke · d_rijit = 0` (abs 1e-9 · ‖ke‖) — unit
- [ ] **K3** Düğüm sırası bağımsızlığı: düğümlerin 24 permütasyonunun hepsinde (sol el sıraları dahil)
  yeniden sıralanmış `ke` ve `σ` aynı (rel 1e-12) — unit
- [ ] **K4** Döndürme değişmezliği: eleman ve yer değiştirme alanı rastgele bir `R` ile döndürülünce
  `ke' = T ke Tᵀ` (`T = blok-köşegen R`) ve gerilme tensörü `R σ Rᵀ` — unit
- [ ] **K5** `D` matrisi: `ν = 0`'da `D = diag(E, E, E, E/2, E/2, E/2)`; tek eksenli gerilmede
  (`σ_xx = σ`, diğerleri 0) `D⁻¹ σ = [σ/E, −νσ/E, −νσ/E, 0, 0, 0]` — unit
- [ ] **K6** Hatalar `ModelError`: `dim ≠ 3`, 3 veya 5 düğüm, tekrarlanan düğüm, yassı (dört düğüm aynı düzlemde)
  eleman, `ν = 0.5` ve `ν ≤ −1` — unit
- [ ] **K7** Patch test (Irons): iç düğümleri düzensiz kaydırılmış (simetrisiz) bir küp ağında sınır
  düğümlerine genel doğrusal alan `u = u0 + H x` (`H` 3x3, simetrik olmayan) yazılır, iç düğümler serbest:
  iç düğüm yer değiştirmeleri `u0 + H x` (abs 1e-10 mm), her elemanda `σ = D ε(H)` (rel 1e-9) —
  `tests/benchmarks/test_tet4.py::test_patch_*`
- [ ] **K8** Tek eksenli çekme prizması (`L × b × h`, uçta düzgün çekme `σ`, sadece simetri düzlemi mesnetleri):
  `u_x(L) = σL/E`, yanal daralma `u_y = −νσy/E`, `u_z = −νσz/E`, her elemanda `σ_xx = σ`, diğer bileşenler
  `≤ 1e-9 σ`; her ağ boyunda tam (rel 1e-9) — `test_tension_*`
- [ ] **K9** Global denge: her 3B testte `Σ R + Σ F = 0` her eksende ve moment dengesi `Σ x × (R + F) = 0`
  (abs 1e-8 · `|F|·L`) — benchmark
- [ ] **K10** Konsol kiriş yakınsaması (`L = 100, b = h = 10` mm, `E = 210000` MPa, `ν = 0.3`, ankastre uç
  tamamen tutulu, serbest uçta `P = 1000 N` düzgün kayma yükü olarak düğümlere dağıtılmış; ağ `10k × k × k`
  altı yüzlü kutu, her kutu 6 tetrahedrona (Kuhn bölümü) ayrılır, `k = 1, 2, 4, 8`). Referans Timoshenko:
  `δ_T = PL³/(3EI) + PL/(κGA)`, `κ = 5/6`. `δ_uç` = serbest uç yüzündeki düğümlerin `−u_z` ortalaması.
  (Ön hesap: `δ_uç/δ_T` ≈ 0.22, 0.50, 0.79, 0.93.)
  - `W = Fᵀu` her incelmede **artar** (iç içe ağ, alt sınır) ve `δ_uç < δ_T`
  - Hata oranı `e_k = 1 − δ_uç/δ_T`: `e_2 / e_4 ≥ 2` ve `e_4 / e_8 ≥ 2`
  - `k = 8`: `δ_uç / δ_T ≥ 0.90` (`@pytest.mark.slow`)
  — `test_cantilever_*`
- [ ] **K11** Mekanizma: tek düğümü tamamen tutulu (dönme serbest) tet ağı → `ModelError` (SPEC 01 pivot testi) —
  benchmark
- [ ] **K12** `post.element_stress_tensors` her tet4 için (6,) dizi verir; `solve()` tet4 modelinde
  `element_forces` / `element_stresses` boş; `bar1d` sonuçları değişmez (mevcut testler yeşil) — unit
- [ ] **K13** `examples/11_tet4_cekme.json` (küçük çekme küpü) `Model.from_json` + `solve` ile çözülüyor ve K8 değerini
  veriyor — benchmark
- [ ] Tüm testler yeşil: `pytest --uygulanmamis-hata` → 0 failed, `ruff check .` ve `ruff format --check .` temiz
